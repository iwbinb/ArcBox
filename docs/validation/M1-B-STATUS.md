# M1-B · 正式网站骨架

日期：2026-09-24。状态：**本地实现与浏览器 QA 通过；远端 PR 检查单独核对。**本阶段只交付无资金演示网站，不构成 Cloudflare 预览部署、钱包接入或六工具业务验收。

## 交付范围

- 把 M1-A 已选定的任务搜索首页视觉迁入正式 `apps/web` 构建入口；六工具目录、场景搜索、移动导航与中英文界面均可操作。
- 六个工具各有详情页：适用对象、三步流程、具体示例、关键规则和常见问题。详情文案沿用对应工具规格及资金边界；成团按付费席位和截止时间判定，分账仅接收已解除退款责任的收入。
- 每个工具可进入三步演示创建向导。名称、说明、USDC 示例金额会实时出现在摘要中；金额以十进制字符串校验最多 6 位小数，不产生订单。用户可显式保存浏览器本地草稿，并在“我的记录”恢复。
- 公开操作页按工具分别标明付款、报名、分账领取、阶段入金或奖励领取，只展示项目、金额、业务记录、钱包、网络、业务合约和规则的核对位置。记录、钱包与合约均明确为未创建或未连接；资金动作按钮禁用，不调用 API、钱包或链。
- 搜索无结果、没有草稿、表单校验错误、钱包不可用及未知路由均有可恢复页面或提示。
- React、React DOM 与图标使用固定版本和锁文件；类型检查覆盖正式站点 TSX，原 M0 工具链和 Worker 构建仍运行。
