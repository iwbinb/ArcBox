# Delivery 02 · 测试与验收矩阵

**状态：以下全部是待执行的验收计划，不是通过报告。**每个工具文件另有10条具体用例，共60条；本文件补共享/跨工具/部署与安全测试。

## 1. 测试层级

域单测：金额、规范化规则、期限、状态投影。合约单测/模糊/不变量：资金守恒、权限、并发与边界。Workers集成：D1事务/outbox、队列重放、文件授权。浏览器E2E：钱包、双语、移动端、状态恢复。测试网/主网小额：实际依赖与真实链行为，需明确授权。

测试记录必须注明mock/local/testnet/mainnet，不能互相替代。生产大额安全不能由测试网成功直接推出。

## 8. 资金不变量性质测试

在随机的付款/退出/证明/提交/争议/结算/领取序列下，每步检查tokenBalance≥全部剩余负债；所有已识别流入可分解为剩余负债+已转出/外部结算；任何实体只分配一次本金；无权限者不能改变受益人；任意等待不会凭空产生平台收入。

包含随机时间推进、最大角色/名单规模、微额舍入、转账失败和多actor交替调用。测试通过仍非数学证明；独立审查另外安排。
